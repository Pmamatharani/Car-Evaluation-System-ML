# Car Evaluation System Using Machine Learning

## Project Description
This project uses Machine Learning to predict car acceptability based on different car features.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Decision Tree Classifier

## Dataset
UCI Car Evaluation Dataset.

## Machine Learning Algorithm
Decision Tree Classifier.

## Model Performance
- Accuracy: 96%
- Test Samples: 346

## Output
The model classifies cars into four categories:
- Unacceptable
- Acceptable
- Good
- Very Good

## How to Run
1. Install required libraries.
2. Run `python car_evaluation.py`.

## Conclusion
The project successfully demonstrates how Machine Learning can classify cars based on their features.
